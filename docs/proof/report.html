What these numbers prove.

A passing sustained run establishes a tested load for this machine, source, workload, and duration. Worker counts bound client outstanding work, including connection waits. Browsing VUs spend time thinking; an arrival-rate test schedules requests independently. None is a count of simultaneous SQLite execution: the engine serializes database work.

Read the limits with the result.

  • The load generator and server share this machine. Client CPU, memory, sockets, and measurement output can constrain observed capacity.
  • Loopback measurements exclude phone Wi-Fi, Internet latency, TLS, and public-tunnel overhead.
  • The largest tested pass is a lower bound under its workload. A failed stage does not isolate the server's absolute ceiling.
